# C4 玩家备注 + 分支预测 · 实施方案

> 状态：已确认并落地（2026-07-30）·范围 A（理解 A·后果预览）·按钮置于选项区下方·v1 单条文本框
> 依据：docs/34 §2.2（C4「玩家备注 + 分支预测」P2 ⬜）、docs/开发状态与审计手册 §2.2（C4 ⬜）
> 定位关键词：**「玩家主导的可控叙事」**——补「玩家主观意图」与「后果预览」两个空档，不引入新依赖、不污染涌现叙事。
> 范围结论（已与黎总对齐）：分支预测走**理解 A（后果预览）**，不做理解 B（预生成可选剧情线）。

## 1. 现状（已核实代码，非记忆）

- **作者注 `author_note`**：world 级、由**世界创作者**写、`S.currentWorld.author_note`，每轮经 `prompt.js::buildAuthorNote()` 注入中部槽位（`llm.js` 组装为独立消息）。这是"作者视角"的常驻约束，已做（B2）。
- **行为记忆 `behavior_records`**：由 **AI 自动记**（玩家可置顶/删除），已做（C1–C5）。这是"AI 视角"的记忆。
- **玩家自由书写的持久笔记**：无。grep 确认全项目无 `player_note` 痕迹——"玩家自己想记住/想达成的东西"目前没有任何载体。
- **分支预测**：无。当前每轮 AI 已给 2–4 个「做什么」的选项，但没有"做了会怎样"的**方向性预览**。

> 结论：C4 要补的是**玩家主观意图（笔记）**与**后果预览（前瞻）**两块，二者都和已有 author_note / behavior_records / choices 互补、不重复。

## 2. 目标

- 玩家能写自己的备忘，AI 后续剧情会"记得"这些意图。
- 玩家想看走向时，点一下就能拿到几条**可能方向**（不剧透结局），帮自己做决定，但不替他选、不改已经发生的剧情。

## 3. 推荐范围 A（轻量 · 零新依赖 · 可逆向）

### A-1 玩家备注（player notes）

- **存储**：运行时 `S.playerNotes`（v1 用**单条多行文本**：`string`，简单可靠）；进入游戏从当前存档读入，自动保存/退出时写回 `save.player_notes`。
  - 归属**存档级**（一个周目里的私人批注），**不进 world**——world 是多档共享模板，放 world 会串档。
- **注入**：新增 `src/prompt.js::buildPlayerNote()`，读 `S.playerNotes`，做长度上限裁剪（参照 B4 预算思路，约 ≤600 字，超长截断并附「…(已截断)」），作为独立一段「【玩家笔记（你自己的备忘，请酌情纳入叙事）】」拼进 `buildAuthorNote` 同一处（`llm.js` 组装 author_note 消息时追加）。
- **UI**：游戏界面加「📝 我的笔记」按钮 → 弹 modal（仿 `authorNoteModal` / `loreReviewModal` 的 `data-action` 事件委托写法，**禁用原生 confirm**）→ 多行 textarea + 保存 → 写 `S.playerNotes` 并触发存档。
- **性质**：不影响游玩、不阻塞、零额外 AI 调用。

### A-2 分支预测 = 理解 A（后果预览）

- **触发**：游戏界面加「🔮 前瞻」按钮（**按需，非每轮**）。
- **调用**：新增 `src/llm.js::predictBranches()`——轻量**非流式**调用（temperature≈0.3、`max_tokens`≈400），输入 = 世界状态摘要 + 近期对话 + 玩家笔记（若有）；模板要求返回 2–4 条**可能方向**，每条 `{branch, likely, risk}`，且**只给方向、不写具体结局/数字/胜负**（防剧透、防变选单游戏）。复用现有 `parseJsonLoose` 宽松解析。
- **展示**：弹窗/卡片列出方向（仿 `deadlineEditorModal` 风格），**纯展示、不落库**——不写 history、不改 `gameState`、完全可逆、不污染涌现叙事。
- **成本**：每次点击 1 次 LLM 调用（按需，可控），与每轮生成完全分离。
- **可选增强（v1 不做）**：把某条方向「一键记进我的笔记」（转 A-1 文本）。

## 4. 明确不做的边界

- ❌ **理解 B（预生成完整可选剧情线让玩家选）**：与「AI 显式推进、涌现式叙事」定位冲突，易把故事变成选单游戏；本次不做（见 §7）。
- ❌ 分支预测**落库 / 改写剧情**：纯展示。
- ❌ 玩家备注进 world（串档风险）：只在存档级。
- ❌ 不引入新依赖、不改已有数据模型大结构（仅给 save 加一个 `player_notes` 字段）。

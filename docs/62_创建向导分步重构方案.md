## 1. 背景与痛点

黎总反馈：创建新世界弹窗「逻辑太繁琐，界面也很丑」。

现状（docs/52 W2-Style 编辑器长页）：

| 痛点 | 具体表现 |
|---|---|
| 信息过载 | 左侧 5 模块长页，单页塞 7+ 字段，必填/可选混杂，新手不知哪些必须填 |
| 无引导 | 底部只有「取消 / 确认生成」，没有"下一步"，需自己点左侧导航 |
| 视觉朴素 | 灰底侧边导航 + 表单堆叠，缺层次、无进度感 |

## 2. 已拍板决策（2026-08-04，黎总选定）

- **交互形式：分步向导**（一步一步引导，每步聚焦一件事；底部上一步/下一步/跳过）。
- **功能取舍：全部保留**——人物卡/背包/羁绊预设、12 风格模板、时间系统、模块开关、特殊要求等一个不删，只重新排布分层。

## 3. 新结构：6 步向导

| 步骤 | 名称 | 内容（从现有模块迁移） | 可跳过 |
|---|---|---|---|
| 1 | 世界设定 | 世界名称★、参考作品、上传源文件、世界观描述★、折叠：关键偏离 | ❌（必填步） |
| 2 | 叙事风格 | 12 风格模板网格、文风文本、温度滑块、折叠：结构化标签 | ✅ |
| 3 | 叙事视角 | POV 单选大卡（单人主角/群像剧）、剧情自由度滑块 | ✅（有默认值） |
| 4 | 玩法时间 | 14 模块开关（卡片化）、时间推进预设 + 时间编辑器 | ✅（有默认值） |
| 5 | 角色资源 | 6 个预设容器挂载（人物卡/变量/背包/技能/目标/支线），整步可跳过 | ✅ |
| 6 | 确认生成 | 配置摘要卡（8 项，每项带「修改」回跳）、折叠：特殊要求、校验面板、生成按钮 | — |

导航规则：
- 底部：左「上一步」（第 1 步禁用），右「下一步」/末步「✦ 确认生成」；可跳过步骤显示「此步可跳过 →」。
- 顶部步骤条：6 圆点 + 连线，已完成步骤打勾、可点击回跳；当前步骤发光高亮。
- 第 1 步未填必填项时「下一步」给出轻提示（不弹窗、不阻断浏览后续步骤的只读查看——实施细节待定，倾向：允许往后看，但末步生成按钮按校验面板拦截，复用 docs/61 现有校验逻辑）。

## 4. 视觉改造点

- 步骤条替代左侧导航栏（横向、顶部居中，省出内容宽度）。
- 每步一个 seri 大标题 + 一句引导语（标注哪些是必填、能否跳过）。
- 世界名称用加大输入框（hero 样式）；单选项改为大卡片（choice-card）；模板卡/模块开关卡片化、选中态描边发光。
- 高级项（关键偏离/结构化标签/特殊要求）统一收入折叠区，默认不打扰。
- 全部复用现有 CSS 变量（`--primary`/`--card`/`--serif` 等），明暗双主题自动适配，不引入新色值。
- 切换步骤用 fadeSlideIn 动效（现有 keyframes 复用）。

## 5. 影响范围（实施时）

| 文件 | 改动 |
|---|---|
| `index.html` | `#createWorldModal` 内部结构重排：左侧 nav → 顶部步骤条；5 个 `.cw-module` → 6 个 `.wz-pane`；底部 footer 加上一步/下一步/跳过。字段 id 全部不变（逻辑零迁移成本）。 |
| `styles.css` | 新增步骤条/卡片/底部导航样式（`.wz-*` 前缀，与旧 `.cw-*` 区分）；旧 `.cw-nav` 等删除或留壳（实施时清理）。 |
| `src/wizard-editor.js` | `selectCwModule` → 步骤导航逻辑（next/prev/skip/gotoStep + 步骤条渲染）；模块切换改为 pane 切换。 |
| `src/render.js` / `src/app.js` | 打开弹窗时重置到第 1 步；接线不变（字段 id 不变）。 |

关键原则：**只动"骨架与皮肤"，不动"神经"**——所有输入控件 id 保持原值，现有读取/校验/生成逻辑无需适配。

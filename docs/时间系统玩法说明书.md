# 时间系统玩法说明书（作者向 · T-2）

> 给用 AetherNarrator 写文字游戏的你。本文**不碰代码**，只讲两件事：① 你在界面上怎么把时间配成「那个世界该有的样子」；② 你在剧情里怎么自然地让时间往前走、倒流、分叉。
> 机制权威版见《时间系统完全手册》；本文是它的「写法实战篇」。

---

## 0. 这份说明书解决什么

你建好世界后，往往希望时间有「世界感」：

- 修仙世界：闭关三月，出来物是人非；
- 克苏鲁：永远停在 1920 年代的某个冬夜；
- 道诡异仙：现实过 1 天，异界可能过 1 年；
- 轮回题材：穿回去重走一遍，事件重新触发。

时间系统就是干这个的。下面的例子你都能直接抄。

---

## 1. 一图看懂：时间系统能做什么

| 能力 | 一句话 | 你会在哪用到 |
|---|---|---|
| 真实日历 | 公历 / 农历 / 自定义历法，带真实年 / 月 / 闰年 | 历史、现代、古风、科幻 |
| 大段时间跳跃 | 闭关、沉睡、远行，时间一键往前跳 | 修仙闭关、植物人苏醒 |
| 虚构历法 | 每个世界用自己的月份表（星历 / 魔历） | 奇幻、科幻自有历法 |
| 双世界穿梭 | 现实 / 异界时间各自走 | 道诡异仙式双线 |
| 时间穿越 + 四策略 | 回到过去、重走、或分叉 | 轮回、平行世界 |

---

## 2. 第一步：在「世界时间体系」卡里配好

位置：创建（或编辑）世界时的 **🌐 世界时间体系** 卡片。**进游戏后锁定**，防止游玩中误改。

你要填的只有四样：

1. **纪元文字（`era_label`）**：写「1920年代」「大清乾隆年间」「星历3024」这种**文字感**的。**千万别只填裸数字年份**——年份请写进这串文字里。
2. **历法模式**：下拉选 5 种之一（见下表）。
3. **起始月·日**：年已经不让你填了（年份靠 `era_label` 表达），只填月 / 日，可空。
4. **多时间线**：只有选「多时间线」结构时才出现（见 §6）。

| 历法模式 | 显示样例 | 适合 |
|---|---|---|
| `day` 第 N 天 | 第 53 天 | 不强调日期的通用世界 |
| `gregorian` 公历 | 1926年2月2日 · 周二 · 深夜 | 真实 / 半真实、现代 |
| `lunar` 农历 | 农历正月初九 | 古风、民俗 |
| `custom_calendar` 自定义历法 | 星历3024 · 熔火月初3 | 科幻 / 奇幻自有历法（用 UI-1 配） |
| `none` 不显示时间 | 相对标签「第五十三天」 | 后室类「时间模糊」世界（后室强制用 none） |

> ⚠️ 填了非法日期（比如平年 2月29），卡片会红字提示并自动纠正，不会让你存错。

---

## 3. 写法示例①：真实起点（别把年份写死）

**坑**：如果你在开场白里写死「现在是 1926 年」，以后时间一跳，文字却不跟着变，玩家就会看到矛盾。

**正确做法**：用占位符，时间系统会自动替换：

```
现在是{era_label}。{calendar_date}，波士顿的雾还没散……
```

- `{era_label}` → 显示「1920年代」
- `{calendar_date}` → 显示「2月2日」
- 还有 `{calendar_year}` `{calendar_month}` 可用

这样无论时间怎么跳，文字永远跟最新日期走。

---

## 4. 写法示例②：大段时间跳跃（闭关 / 沉睡 / 远行）

你**不需要手动改日期**。在剧情里自然写推进，AI 会按世界设定把日期往前挪：

> 他盘膝入定，这一闭关，便是三个寒暑。

AI 在背后把日期推进三个月（闭关）/ 或跳到指定历史节点（苏醒）。底层它用的指令长这样（你不用手写，知道有这回事即可）：

- 相对 +N 天：`addDays:90`（远行）
- 相对 +N 月：`addMonths:3`（闭关，月末自动夹紧）
- 绝对跳到某天：`{year:2004, month:6, date:16}`（植物人苏醒跳到 2004）

> **向前跳（时间变大）一律放行；向后倒流（时间变小）默认也放行**（黎总拍板允许时间倒流）。倒流时事件怎么处理，看下节。

---

## 5. 写法示例③：时间穿越 + 四种策略

时间倒流时，已经触发过的事件怎么办？有四招，互不打架：

| 策略 | 行为 | 适合 |
|---|---|---|
| **S1 不重触发（once，默认）** | 已触发的事件穿回去也不重播 | 生日、历史性节点 |
| **S2 可重复（repeatable）** | 带次数上限 + 冷却，到窗口再触发 | 每日商情、周期怪潮 |
| **S3 重置重走（reset）** | 穿回去时把触发记录清空，重走这段 | 轮回、roguelike 时间循环 |
| **S4 分支平行（branch）** | 穿回去时开一条新时间线，原未来保留 | 量子分叉、平行世界 |

**你怎么做**（纯界面）：

- 在世界时间体系卡里设 **默认穿越策略**（`keep` 保留 / `reset` 重置 / `branch` 分支）；
- 每条时间线还能单独覆盖。
- 优先级：你给 AI 的穿越指令 > 单线覆盖 > 世界级默认 > 回落 keep。

> 只有「逆跳（日历变小）」才套用这些策略；**向前跳永远放行**，不触发重置 / 分支。

**「轮回世界」配置示例**：把默认策略选 `reset`，玩家每次穿回开头，剧情事件重新触发，就是标准的 roguelike 时间循环。

---

## 6. 写法示例④：双世界 / 多世界（multiverse）

想做「现实 / 异界」双线？在世界结构里选 **多时间线**，用 UI-2 配置器：

- 增删时间线（每条一个独立身份，如「现实 / 异界」）；
- 一键「双界穿梭」模板，直接载入 earth / xianxia 两线预设；
- 每条线内还能嵌自定义历法、独立时钟 / 天气。

**玩法效果**：切换世界 = 切活动线，每条线时间独立走。

**流速比（sync_rules）**——让两界时间流速不同：

> 异界过 1 天 = 现实过 1 年

配置就是给某条线设：`ref` 指向另一条线，`ratio` = 本线推 1 天 ⇒ 参考线推多少天（可以是小数）。道诡异仙那种各自独立、不想同步的，不配就行。

---

## 7. 写法示例⑤：截止事件（deadlines）

想做「三日后比武」「月底前交租」这种倒计时？在世界时间体系卡里配 `deadlines`：

- 触发时间（月 / 日 / 时段）；
- 重触发策略 `retrigger_policy`：
  - `once` 一次性（历史性节点）；
  - `repeatable` 可重复，带 `max_repeats`（次数，0 = 无限）+ `cooldown_steps`（冷却）。

时间到了，AI 自动触发对应事件。你只管写配置，不用管倒计时逻辑。

---

## 8. 写法示例⑥：自定义历法（不用写 JSON）

选 `custom_calendar` 模式，会弹出 UI-1 可视化编辑器：

- 给历法起名（「艾欧历」「星历」）；
- 可视化增删月份、改名、改每月天数；
- 一键插「闰 X 月」；
- 模板预设：农历 / 科幻历 一键载入；
- 实时看「共 N 个月 · 一年约 M 天」。

**全程鼠标点，不用碰 JSON。**

---

## 9. 农历 / 节气（已做 · C-1，2026-07-29）

`lunar` 模式已带节气显示：游戏内时间条会显示「农历正月初九（立春～雨水）」这样带着当月节气的日期，AI 也知道每月对应的节气（正月立春/雨水、二月惊蛰/春分……腊月小寒/大寒），方便借清明、冬至等节气推进剧情。

需要**闰月**的古风世界（如某农历年有闰二月）：本工具不在 `lunar` 模式里直接做闰月（会与 12 月进位冲突），而是改用「自定义历法」模式，在编辑器里点「📅 农历(含闰月)」模板一键载入含闰月的月历表，再用「＋闰」按钮插入其它闰月即可。

## 10. 避坑清单（必看）

- **季节已彻底移除**（方案 23）：别再配季节字段，开场白也别用 `{season}` 占位符（旧档残留会自动清空）。
- **别写死年份**：用 `{era_label}` `{calendar_date}` 等占位符，否则时间跳了文字不跟、弹出「⚠ 时间可能冲突」徽章。
- **时间倒流默认允许**：不想某事件重播，用 `once` 策略锁死。
- **年份靠 `era_label`**：起始日期不填年，年写进纪元文字里。
- **新世界才有完整新能力**：老存档 / 老世界不回填（黎总拍板重新生成世界），旧档关系页签只有文字层、没数值条。

| 我想做… | 在哪配 | 用哪个能力 |
|---|---|---|
| 固定年代感 | 世界时间体系卡 · 纪元文字 | `era_label` |

| 闭关 / 沉睡跳跃 | 剧情里自然写，AI 推进 | 大段跳跃 |

| 平行世界分叉 | 默认穿越策略选 branch | S4 |

| 异界1天 = 现实1年 | 流速比 ref + ratio | sync_rules |

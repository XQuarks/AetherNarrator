# docs/61 · 创建向导「模块门禁 + 关联校验 UI + 好感度群像门禁」

> 2026-08-04 黎总拍板（本轮直接指令 + AskUserQuestion 两项决策）。

## 1. 需求（黎总原话要点）

1. **做容器间关联校验 UI**：向导里填的内容与模块开关、叙事视角之间的一致性检查。
2. **模块门禁 → 编辑器显隐**：开了哪个玩法模块，才有对应功能编辑（例：开了时间系统模块才有时间系统编辑）。
3. **好感度进角色编辑**：编辑角色时就能编辑好感度（NPC 初始好感 + 关系标签）。
4. **群像剧例外**：pov=ensemble（群像剧）→ 角色卡不显示好感度/关系编辑；角色间关系与好感改从「给 AI 的备注」填写。

## 2. 已确认决策（AskUserQuestion）

| 决策点 | 选择 |
|--------|------|
| 校验力度 | **错误拦截 + 警告放行**：明确矛盾（好感度但模块未开 / 群像剧设好感度等）→ 点「确认生成」拦截并提示；角色名重复等仅警告不阻断 |
| 门禁样式 | **隐藏 + 占位提示**：未开模块的编辑卡片直接隐藏，显示「开启XX模块后在此编辑」占位 |

## 3. 实现设计

### 3.1 模块门禁（编辑器显隐）
- 每个容器卡片配置新增 `moduleGate`：variables→variables / inventory→inventory / skills→skills / goals→goals / sideEvents→events；characters 为核心恒开（moduleGate=null）。
- `renderContainerCard`：对应模块未开 → 渲染占位卡片（标题 + "开启「X」模块后在此编辑"），不渲染编辑区；数据保留在缓冲不丢。
- 时间系统 section：`refreshTimeGate()` 读 `#moduleToggles input[data-module="time"]` → 未开则隐藏 `#timePresetFields`、显示占位。
- 模块开关 change / pov change → 刷新容器渲染 + 校验面板（wizard-editor.js 绑定监听）。

### 3.2 好感度门禁（角色卡内）
- 角色卡渲染时按状态过滤字段：
  - `affinity` / `rel_tags`（B4 内容）：仅当 affinity 模块开启 **且** pov=solo 时显示；affinity 模块关 → 隐藏并提示"开启『羁绊好感度』模块后可设置"。
  - `relationship`（与主角关系）：仅 pov=solo 时显示。
  - **群像剧（pov=ensemble）**：隐藏 relationship/affinity/rel_tags，显示提示"群像剧无单一主角：角色间关系与好感请在『给 AI 的备注』中描述"。
- 数据层：`shapeWizardContainers(buffers, opts)` 新增 opts `{modules, pov}`；pov=ensemble 时 characters 数据剥离 affinity/rel_tags（不落库）；enableModules 仅包含「已开启模块 + 填了内容」的（opts 缺省视为全开，向后兼容 docs/60）。

### 3.3 关联校验 UI
- 纯函数 `computeWizardValidation({buffers, modules, pov})` → `{errors, warnings, infos}`：
  - **error（拦截生成）**：填了好感度/关系但 affinity 模块未开；填了变量/技能/背包/目标/支线但对应模块未开；群像剧却设了主角卡；群像剧却填了好感度。
  - **warning（不阻断）**：角色名重复。
  - **info（不阻断）**：solo 无主角卡（AI 自动设计）。
- `renderValidationPanel()` 渲染到 `#wizardValidationPanel`（向导底部），error 红色 / warning 黄色 / info 灰色；error 项带「去开启」按钮（勾选对应模块 + 触发 change 联动刷新）。
- 实时刷新：输入 / 模块开关 / pov 变化时重新校验。
- `game.js::generateWorld`：基础校验后调 `validateWizardContainers()`，存在 error → toast 第一条 + return 拦截；并自动切到「生成设置」/保持当前模块展示面板。

### 3.4 时间系统门禁
- `getWizardTimePreset`：time 模块未开 → 返回 `{key:"none", hint:""}`（不注入时间提示）。

## 一、目标

在「创建/编辑世界」的时间体系卡里，当世界选择 **多时间线（multiverse / 双界穿梭）** 结构时，提供**可视化配置器**让用户：

- 切换世界结构：单一时间线 ↔ 多时间线（multiverse）；
- **图形化增删时间线**（每条线一个独立身份，如「现实 / 异界」）；
- 为每条线设 **历法（calendar_mode）**、**纪元/年份文字（era_label）**、**初始日期（year/month/date）**；
- 指定 **当前活动线（active_timeline）**（游戏开局所在的那条）；
- 取代当前"multiverse 起始日期只能在代码中配置"的提示（`src/lore-ui.js:127-129` 的 `multiverseHint`）。

**替代**当前 `multiverseHint` 的占位文字（引擎早已支持该结构，仅缺 UI）。

## 三、数据结构（落点）

每条时间线 `time_config.timelines[id]` 归一化后字段（来自 `normalizeTimeConfig`）：

```js
{
  name: "现实",            // 显示名 ≤30
  calendar_mode: "gregorian", // day|gregorian|lunar|custom_calendar|none
  calendar_start: { year, month, date }, // 纪元锚点（保存时由初始日期推导，保证有锚）
  current_date: { year, month, date, period? }, // 开局所在日期（游戏起点）
  era_label: "公元2003年", // 纪元文字 ≤40
  weather: "",             // ≤20
  custom_calendar: null    // 仅当该线 calendar_mode==="custom_calendar"
}
```

顶层：`time_config.mode`（`"single"` | `"multiverse"`）、`time_config.active_timeline`（指向某条线 id）。

**UI 暴露字段（每条线）**：名称、历法下拉、纪元文字、初始日期（年/月/日）、是否为活动线（单选）、删除。
- 保存时：把"初始日期"同时写入该线 `current_date` 与 `calendar_start`（保持锚一致，引擎 `validateStartDate` 需要锚）；`active_timeline` 取选中线。
- 顶层 `initial_state.current_date` 在保存/生成时取 active 线的 `current_date`（与 `new-worlds.js` 双界样例一致）。

## 四、设计

### 4.1 世界结构切换（前置，必做）

在 `renderTimeConfigSection` 顶部新增「世界时间结构」单选/下拉：
- **单一时间线（single）** → 维持现有单线表单（纪元/历法/起始日期/自定义历法编辑器）。
- **多时间线（multiverse / 双界穿梭）** → 隐藏单线表单，渲染 `renderMultiverseEditorInner()`。

切换时（结构性操作，局部重渲染 `#mvEditorWrap`）：
- 切到 multiverse：若 `time_config.timelines` 为空，用当前单线配置 **seed 一条默认线**（id=`main`，名称取现有纪元或"主线"，calendar_mode/era/起始日期继承当前单线值），避免作者从头填。
- 切回 single：保留 `timelines` 不删（仅隐藏），`mode` 改回 `single`；作者再切回多线不丢数据。

### 4.2 多时间线编辑区（multiverse 模式显示）

`#mvEditor` 内逐线渲染卡片（复用 `time-cfg-cc` / `cc-*` 样式族，保持一致观感）：

每条线卡片含：
1. **线 ID（key）**：文本输入 `data-mv="mv-id"`（字典键；改名时整体替换 key，迁移该线数据到新 key，并修正 `active_timeline`）。
2. **名称**：`data-mv="mv-name"`（≤30，空则回退 ID）。
3. **历法**：`data-mv="mv-cal"` 下拉（复用 `CALENDAR_LABELS`）。
4. **纪元/年份文字**：`data-mv="mv-era"`（≤40）。
5. **初始日期**：年/月/日三个数字输入（dated 历法显示；day/none 隐藏年/月/日，仅留纪元文字）。
6. **活动线**：单选 `name="mv-active"`（选中 → `active_timeline=该id`）。
7. **删除**：`data-action="mvDelLine"`（线数=1 时禁用，至少留一条）。

底部：**＋ 添加时间线** 按钮（`data-action="mvAddLine"`）：追加 `{ id:"line_N", name:"新时间线", calendar_mode:"day", current_date:{year:1,month:1,date:1}, era_label:"" }`。

文本输入仅写回数据 + 刷新统计/校验，不重渲染输入框（沿用 UI-1 防丢焦点做法）；结构性操作（增/删/改名/切结构/切活动线）才局部重渲染 `#mvEditor`。

### 4.3 只读模式

`renderTimeConfigSection("save")` 时，按现有 world/save 区分：多线卡片渲染但输入框 `disabled`、隐藏增删按钮（与 UI-1 只读处理一致）。

### 4.4 回读

新增 `readMultiverseFromDOM(tc)`（类比 `readCalendarStartFromDOM`）：遍历 `#mvEditor` 线卡片 DOM → 组装 `tc.timelines` + `tc.active_timeline` + `tc.mode="multiverse"`；保存时由 `normalizeTimeConfig` 兜底夹紧。接入现有 `syncTimeConfigFromDOM` 分支（当 `mode==="multiverse"` 走多线回读，否则走原单线回读）。

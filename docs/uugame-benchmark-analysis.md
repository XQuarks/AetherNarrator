## 一、核心结论（ TL;DR ）

UU Game 是一个**平台化、移动端优先、创作者生态驱动**的 AI 文字冒险/模拟经营产品。它的强项在于：

1. **极低的创作门槛**：向导式开局 + AI 一键生成世界观 / 规则 / NPC / 开场白。
2. **结构化的游玩节奏**：主线“面板”+ 支线“事件”+ 体力消耗 + 时间推进，让玩家有清晰的“回合感”。
3. **丰富的副系统**：手机（通讯录 / 论坛 / 日记 / 应用商店）、世界地图、CG 画廊、结局条件，形成 IP 内的“模拟人生”体验。
4. **高自由度的玩家设置**：引擎档位、AI 温度、文风、叙事节奏、字数、阅读速度、主题 / 字体 / 壁纸都可调。
5. **平台货币化与创作者经济**：UU 币按引擎倍率计费、应用商店允许创作者卖/下载小 App、云端存档、兑换码体系。

AetherNarrator 的差异化优势在于**纯前端本地运行、中文 RAG 知识库、深度自定时间系统、结构化容器（人物卡 / 背包 / 好感度 / 玩家变量）和世界规则 DSL**。这些构成了“技术底座更深、数据主权更强”的定位。

**最值得 AetherNarrator 优先学习的三件事**：

- **① 给玩家更强的“阅读节奏”控制**（字数 / 叙事节奏 / 打字机效果 / 流式切换）。
- **② 把“事件”从线性日志里抽出来，做成可管理、可重刷、带消耗的支线面板**。
- **③ 给创作者一套“一键生成 + 向导配置 + 可预览”的低门槛开局流程**。

## 二、UU Game 机制与界面拆解

### 2.1 产品形态与定位

| 维度 | UU Game | AetherNarrator（当前） |
|------|---------|------------------------|
| 运行形态 | 平台（Web / 移动端 H5），需登录，数据上云 | 纯静态前端，本地 IndexedDB，无账号 |
| 商业模式 | UU 币计费 + 创作者应用商店 + 充值 | 无内置计费，用户自填 API Key |
| 目标用户 | 泛二次元/女性向玩家 + 轻度创作者 | 对 AI 叙事、IP 还原、数据隐私有要求的玩家/作者 |
| 默认 UI | 移动端竖屏、底部四 Tab、卡片式 | 桌面+移动自适应、单页日志流、顶部状态栏 |

### 2.2 创作端：从零到可玩作品

UU Game 把创作拆成四类产品，降低心理门槛：

1. **创作剧本**：AI 文字冒险世界（属性 / NPC / 时间线 / 剧情走向）。
2. **创作 AI 应用**：对话生成可独立运行的小游戏 / 工具网页。
3. **创作手机内部 App**：可装进游玩页“手机”里的 App，能读取剧本上下文。
4. **导入代码文件**：已有 HTML/CSS/JS 导进去继续用 AI 迭代。

**关键创作流程（以“创作剧本”为例）**：

```
选择叙事文风（日常治愈 / 热血冒险 / 晋江文风）
  → 填写游戏标题 + 游戏指令（世界观 / 玩法 / 登场角色，最多 5000 字）
  → 选择生成引擎（畅聊 0.35× / 标准 0.5× / 露娜 0.6× / 疾风 1× / 专家 1× / 疾电 2.2× / 太阳 3×）
  → 勾选 AI 生成项（简介与标签、叙事规则、主题配色、角色属性、预设 NPC、开场白）
  → 进入可视化编辑器继续微调
```

**编辑器模块**：

| 模块 | 说明 |
|------|------|
| 基本信息 | 标题、封面、简介、标签、共创者管理 |
| AI 设定 | 共用系统提示词、叙事文风、世界书（关键词命中才注入，避免占 token） |
| 玩法设计 | 属性定义（数值范围 / 默认值 / 是否随机）、初始设置字段、NPC 属性（爱慕值 / 友善值 + 自定义）、头像池、世界地图开关 |
| 时间系统 | 周期标签模板、时间段列表、主线/支线体力、快捷行动、年龄系统、周期收入、固定事件 |
| 结局条件 | 玩家/NPC 属性阈值、多属性同时达成、周期结束触发 |
| CG 画廊 | 条件解锁立绘 CG，全屏播放并自动入收藏本 |
| 手机配置 | 主屏布局、手机主题、各 App 玩法 |

### 2.3 游玩端：四 Tab 结构

底部固定导航：**剧情 / 手机 / 世界 / 设置**。

#### 剧情页

- **面板 Tab**：当前时段主线简报 + 事件列表 + 地图缩略图 + 下阶段日程。
- **事件 Tab**：进入单条支线叙事，专注一条故事线。
- 顶部显示：角色名、体力、当前周期/时间/地点、存读档按钮。
- 点击“推进剧情”进入下一时段，结束当前时段并生成新主线简报。
- 进入支线消耗顶栏“支线体力”；进入后支线内行动不再扣体力。

#### 事件详情页

- 流式生成时右侧有加载动画。
- 左侧菜单：回溯上一幕、收藏当前剧情、重刷剧情。
- 底部：输入自定义行动，或点 AI 生成的选项。
- 事件完结后出现横幅，可回面板继续其他事件。
- 每次交互后明确提示人脉数值（爱慕值 / 友善值）和属性变化。

#### 手机页

模拟手机主屏，可配置：

- **通讯录**：私聊、群聊、好友、朋友圈。
- **论坛**：热搜榜、发帖（可选本命昵称 / 匿名 / 自定义马甲）、按剧情自动更新、自定义规则。
- **日记**：角色视角记录，可同步好友日记。
- **应用商店**：发现/安装其他创作者做的 App（地球银行、剧情推进器、预言家日报、魔法 ins、斗地主、织梦、抖音、万能修改器等）。
- **收藏本**：CG 画廊等。

#### 世界页

- 人脉总览，可导入收藏角色卡。
- 有地图时可前往已揭示地点，移动会生成路途/抵达描写。
- 人物详情弹窗：头像/生图、爱慕值/友善值、描述、TA 对你的看法、常去地点、回忆、事实卡、属性。

#### 设置页

- **剧情引擎**：引擎档位、AI 温度。
- **核心玩法**：游玩模式（游戏模式 / 小说模式）、手动完结事件开关、文风设定、叙事节奏、文字展示（AI 输出优先 / 阅读优先）、阅读速度、事件正文叙事字数、显示行动选项、显示世界地图、记忆方式、记忆管理。
- **外观与显示**：主题风格、字体、大小、背景壁纸、卡片透明度。
- **系统与数据**：存档、访问线路、结束这段故事、帮助说明。
- **UU 币与购买**：余额、充值、兑换码、笔芯掉落（类似抽卡/道具）。

### 2.4 商业模式

- **UU 币按 token 消耗 × 引擎倍率计费**。
- 充值后剧情引擎等平台线路享 8 折，每日可免 UU 币重刷 3 次起。
- **应用商店**让创作者可以把小工具卖给其他玩家，形成二次创作生态。
- 云端存档需登录，换设备可读；自动存档仅在本地。

## 四、可优化 / 可改进方向

### 4.1 短期可借鉴（1-2 周内可出 Demo）

#### ① 玩家侧“阅读节奏”控制

UU Game 在设置里给了非常细的控制：

- 叙事节奏：快 / 中 / 慢
- 文字展示：AI 输出优先（流式）/ 阅读优先（打字机渐进）
- 阅读速度：慢 10 字/秒、中 20 字/秒、快 30 字/秒
- 事件正文叙事字数：最少 / 最多

**AetherNarrator 可补**：

- 在“游戏设置”里加入字数范围（min/max）注入到 system prompt。
- 增加“打字机效果”开关与速度滑块。
- 增加“剧情推进节奏”选项（紧凑 / 标准 / 舒缓），影响 prompt 里的叙事密度指令。

#### ② 把“事件”抽成可管理卡片

UU Game 的核心节奏是：面板看简报 → 事件列表 → 进入支线 → 消耗体力 → 推进时间。

**AetherNarrator 可补**：

- 在日志区上方增加“当前事件列表”面板（可收起）。
- 每条事件卡显示：标题、时间、地点、消耗体力、状态（进行中 / 已完成 / 已过期）。
- 点击卡片进入专注叙事模式，左侧显示事件历史，底部只出与该事件相关的选项。
- 事件完成后允许“重刷”（不推进世界状态，仅回顾/实验）。

#### ③ 给创作者“一键生成 + 向导配置”

UU Game 的创作入口把“写提示词”包装成了“选文风 → 填标题和指令 → 选引擎 → 选生成项”。

**AetherNarrator 可补**：

- 创建世界时增加“叙事风格”预设（日常治愈、热血冒险、晋江、悬疑、黑暗奇幻）。
- 增加“生成深度”选项：只生成开场白 / 生成开场白+选项 / 生成知识库+开场白+初始 NPC。
- 生成后展示“创作完成度卡片”，告诉作者还缺什么（已落地 computeWorldCompletion，只需在创建后展示）。

### 4.2 中期值得探索（1-2 个月）

#### ④ 模拟“手机”副系统

UU Game 的手机是最大差异化体验之一。AetherNarrator 不一定要照搬论坛/商店，但可以考虑：

- **NPC 私聊**：在侧边栏给已登场 NPC 发消息，AI 按人物卡回复。
- **世界日报/公告**：按当前时间/地点生成一段“世界新闻”，增强沉浸。
- **角色日记**：AI 按主角视角自动总结本轮经历，可导出。

#### ⑤ 世界地图与地点移动

- 允许作者上传/配置一张世界地图。
- 地点作为知识库条目，移动时触发“路途事件”或“抵达描写”。
- 与当前时间系统结合，移动消耗时间。

#### ⑥ 结局条件可视化编辑器

- 把现有的世界规则 DSL 包装成“当 [玩家属性] ≥/≤/= 值，或 [NPC 属性] …，或 [周期结束] 时触发结局”。
- 结局文案由 AI 根据玩家一路的属性/关系/抉择生成。

#### ⑦ 视觉奖励：CG / 成就

- 作者可配置 CG 解锁条件（事件完成、属性达标、NPC 好感度达标）。
- 玩家触发后全屏展示 CG，并收入收藏本。
- 与当前“收藏”功能结合。

### 4.3 长期 / 需权衡的方向

#### ⑧ 云端存档与账号体系

UU Game 能做到换设备读档是因为有登录/云端。AetherNarrator 的纯本地定位很强，但代价是：

- 清缓存丢档。
- 无法多端同步。
- 无法做创作者经济。

**建议**：可保留“默认本地”，可选“导出加密存档包到网盘/自托管后端”，不破坏隐私主调。

#### ⑨ 创作者应用商店 / 模组市场

UU Game 的“手机 App”本质是可插拔的小模组。AetherNarrator 已有 Registry 模式的模块系统，理论上可以：

- 允许作者打包模块（JSON + 自定义 prompt/规则）。
- 玩家在世界设置里开关模块。
- 长期可考虑轻量市场，但需先解决存档兼容与版本管理。

#### ⑩ 平台货币化 vs 自接 API

UU Game 靠平台引擎赚 UU 币差价；AetherNarrator 让用户自填 API Key，零抽成。

**建议**：保持“自接 API”主线，但可增加“托管 API 选项”作为可选增值服务（如果未来要商业化），让用户在便利与成本之间选择。

## 五、AetherNarrator 应坚持的差异化

1. **纯前端 / 数据本地**：这是与 UU Game 最鲜明的差异，不要轻易放弃。
2. **中文 RAG 与向量检索**：UU Game 的世界书只是关键词匹配，我们的 bge-small-zh + hnswlib-wasm 是真实的技术壁垒。
3. **深度时间系统**：自定义历法、纪元、流速比、多时间线，面向硬核世界观作者。
4. **结构化容器与模块注册表**：B 系列容器 + Registry 模块让复杂世界可维护。
5. **IP 合规扫描**：在 fan/ip/shared 世界观创作中提前规避版权风险，UU Game 没有同类机制。

## 七、结论

UU Game 是一款**把“AI 文字冒险”产品化、平台化、移动化**的成熟参考。它最值得 AetherNarrator 学习的是：

- **对玩家体验的颗粒度控制**（节奏、字数、视觉、主题）。
- **对“主线 / 支线 / 体力 / 时间”的结构化封装**，让叙事有游戏感。
- **对创作者的低门槛引导**，用向导和 AI 生成把“写 prompt”变成“填表单”。

AetherNarrator 不需要做成第二个 UU Game。它的定位更偏向**“重度作者工具 + 本地隐私优先 + 技术底座深厚”**。最优策略是：

> **用 UU Game 的“面子”（玩家舒适度、事件面板、阅读节奏）补 AetherNarrator 的“里子”（RAG、时间系统、结构化容器、IP 合规）已经很强但不够友好的地方。**

下一步建议先出一份最小改造方案（P0 两项：阅读节奏 + 事件面板），确认范围后再动代码。

> 本手册是 AetherNarrator「**竞品对标 / 借鉴路线图 / IP 一致性**」的唯一年威参考，整合自：`20_竞品功能技术与对标分析`、`28_竞品借鉴总览`、`29_IP一致性统一方案`、`25_竞品创作流程拆解`、`27_竞品叙事系统拆解`。原始方案已移入 `docs/_archive/产品对标/` 留底（`16_竞品对比与改进建议.md` 已废，亦在其中）。

## 1. 我们的定位与护城河

**定位**：纯前端（零后端）AI 文字游戏/叙事模拟器，玩家自定义 IP 世界观、创建角色、AI 生成剧情，本地知识库(RAG)+存档，数据不出本机。

**四大工程亮点（主打卖点）**：
1. **会"自己往前走"的世界**：事件引擎 + 目标链 + NPC 自主活动（多数竞品是单线对话，这是最清晰差异化）。
2. **纯前端 + 本地隐私**：无账号、无上云。
3. **中文 RAG + 世界观守卫**：原生中文分词、IP 违禁概念过滤。
4. **文字描述优先的数值体验**：避免数字污染，更"叙事"。

> 短板与"纯前端零后端"定位强相关（无云同步/多用户/社区/多模态/移动端），这些已降级为「待商业化 Phase 6 平台化再立项」，近期不做。

## 5. IP 一致性统一方案（做哈利波特模拟器必看）

**统一模型 `world.canon`**：把「输 IP 名 / 传源文件 / 自动检测」收敛成往一个字段填信息的三种方式。

- `mode`: `original` / `ip_adaptation`
- `ip_name`: 哪个 IP（用户填 或 `detectIp` 建议）
- `source`: `none` / `description` / `uploaded_text`
- `key_divergences`: 用户声明的关键性修改（如"时间线移到2025、伏地魔已败"）
- `consistency_pack`: `{ banned[], must_read[], style_anchor }` —— **建世界时由 AI 从源文本动态生成**（非静态注册表）

**优先级铁律**（注入 system prompt 时遵守）：
```
用户上传文本 + 用户声明的 key_divergences  ＞  consistency_pack（禁项/必读）  ＞  LLM 训练时的原著先验
```
即：**用户说改了什么，比"原著该怎样"算数。**

**`detectIp()` 辅助建议器**（已落地）：轻量关键词启发式（霍格沃茨→HP、克苏鲁→Cthulhu），只做"识别哪个 IP"的模式匹配，**绝不存储/比对版权原文**（工具不扮演"版权警察"）。

**诚实边界**：本地应用里没有"别人小说原文"，云端模型也没有可靠逐字版权副本；系统**做不到、也不该做**"自动判定上传的是原文 vs 改稿"。一致性真相来源 = 用户上传文本（优先）/ 世界描述。

**实现进度**：#1 一致性包生成+禁项注入 ✅ / #2 `world.canon` 模型+协调器 ✅ / #3 `detectIp` 建议器 ✅ / #4 `key_divergences` 文本框+注入 ✅ / #5 克苏鲁写死禁律改走生成包 ✅ / **#6 生成后硬扫描 ⬜（可选，未做）**。

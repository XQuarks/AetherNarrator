# 以太叙事 · AetherNarrator

零后端的 AI 互动叙事引擎。输入任意一个世界观（原创或已有 IP），AI 立刻生成可玩的文字冒险。纯前端、本地运行，所有数据只存在你自己的浏览器里。

## 它能做什么

- **换个 IP 就能玩**：填入世界观描述或上传原著（TXT/DOCX/EPUB），AI 自动生成知识库、开场白和初始选项。
- **会自己往前走的世界**：事件引擎 + NPC 自主行为 + 目标链，不只是在等玩家推剧情。
- **中文知识库（RAG）**：内置本地中文向量检索，无需联网即可语义召回设定，AI 不再"失忆"。
- **世界自定时间系统**：AI 按 IP 自动生成纪元 / 历法 / 时钟（红楼走阴历、星际走纪元历）。
- **世界规则 DSL**：自定义条件触发禁律 / 解锁 / 结局，运行时强制执行。
- **本地优先、隐私安全**：无账号、无服务端，API Key 与存档只存在浏览器本地 IndexedDB。

## 快速开始

用任意静态服务器打开（不要直接双击 `file://`，浏览器会拦截数据文件）：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

**部署**：推送到 GitHub 后，在仓库 Settings → Pages 选择 main 分支根目录即可；或用附带的 `.github/workflows/deploy.yml` 自动部署到 GitHub Pages。

## 使用流程

1. 首页「进入世界」→ 创建新世界。
2. 选择已有 IP 或原创，填写世界观描述、设定主角，可选上传源文件。
3. 填入 DeepSeek API Key（在「模拟模式」外配置）。
4. AI 自动生成知识库、开场白和初始选项。
5. 自由打字或点选选项，AI 每轮生成叙事 + 状态变化 + 新选项。

> 当前版本主要针对 DeepSeek 模型做了优化（前缀缓存、token 配额等），使用其他模型可能消耗偏高。

## 项目结构

纯静态、零构建。浏览器用 ES Module 直接加载 `src/` 下的模块，GitHub Pages 开箱即用。

```
index.html          # 入口
styles.css
src/                # 主程序：状态、存储、RAG、Prompt、LLM、渲染、游戏规则、知识库 UI
data/               # 预置知识库、初始状态、Prompt 模板
tools/              # 开发期脚本（数据迁移、模块校验等）
vendor/             # 本地依赖：中文 embedding 模型、向量索引、知识图谱渲染（均离线可用）
```
